📚 Расписание факультета
Приложение для управления расписанием студентов и преподавателей.
📝 Описание
Приложение позволяет:

Создавать и редактировать группы, студентов и преподавателей

Добавлять занятия для групп с указанием:

Предмета

Преподавателя

Дня недели

Времени пары

Аудитории

Отображать:

Расписание группы

Общее расписание всех групп

Статистику по студентам, преподавателям и группам(Для облегчения подсчета часов отработки или других критерий преподавателя(студента)

Искать расписание по студенту или преподавателю(Допустим, чтобы было проще найти человека в университете)

Также учтены конфликты, нельзя поставить одного преподаваетеля или группу в одно время.
